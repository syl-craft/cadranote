La sélection n’est pas disponible sur cette page.

Chrome empêche les extensions d’inspecter ses pages internes (chrome://), le Chrome Web Store et certaines pages protégées, dont son lecteur PDF.

Ouvrez une page web classique ou votre application sur localhost, puis cliquez à nouveau sur l’icône de l’extension.

Pour un fichier HTML local, activez Autoriser l’accès aux URL de fichier dans les détails de Cadranote sur chrome://extensions.

Si le problème persiste sur une page ordinaire, rechargez-la puis réessayez.
