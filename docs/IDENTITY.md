# Identité visuelle

**Cadranote — De la page à la consigne.**

Le [logo](../src/ui/logo.svg) associe un C bleu à deux lignes de note. Le panneau s’inspire du thème [Digital Banking](https://uupm.cc/demo/digital-banking).

| Rôle | Couleur |
| --- | --- |
| Fond | `#0b1628` |
| Surface | `#1d2c43` |
| Texte principal / secondaire | `#f1f5fc` / `#b2c1d6` |
| Action principale | `#0866eb` |
| Cible et focus | `#72b5ff` |
| Compléments et ajout | `#36c88d` |

Police système ; monospace pour les sélecteurs. Icônes SVG, contrôles d’au moins 40 px, focus visible et respect de la réduction des animations.

Parcours : **cible → demande → compléments**. Les outils secondaires sont repliables ; la copie IA reste visible en bas du panneau.
